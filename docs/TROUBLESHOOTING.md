# 故障排查指南

## 快速诊断流程图

```
开始
  │
  ├─ 上电无反应 ──→ 检查电源部分
  │                    │
  │                    ├─ 测 USB 5V ──→ 无 ──→ USB 线/接口问题
  │                    │                 有 ──→ 测 3.3V
  │                    │                          │
  │                    │                          ├─ 无 ──→ 稳压芯片问题
  │                    │                          └─ 有 ──→ 主控问题
  │                    │
  ├─ 电流过大 ──→ 检查短路
  │                    │
  │                    ├─ 电源短路 ──→ 检查电容/稳压芯片
  │                    └─ 信号短路 ──→ 检查芯片焊接
  │
  ├─ 无法识别串口 ──→ 检查 USB 部分
  │                    │
  │                    ├─ 驱动问题 ──→ 安装驱动
  │                    ├─ CH340 问题 ──→ 检查焊接
  │                    └─ USB 线问题 ──→ 更换线缆
  │
  ├─ 无法烧录 ──→ 检查下载模式
  │                    │
  │                    ├─ 按键问题 ──→ 检查 BOOT/RST 键
  │                    ├─ 串口问题 ──→ 检查 TX/RX
  │                    └─ 芯片问题 ──→ 检查 ESP32
  │
  └─ 墨水屏不显示 ──→ 检查显示部分
                       │
                       ├─ 排线问题 ──→ 检查连接
                       ├─ 接口问题 ──→ 检查 FPC 焊接
                       └─ 固件问题 ──→ 重新烧录
```

## 一、电源问题

### 1.1 上电无反应

**症状：**
- 插入 USB 线后，电源 LED 不亮
- 设备管理器无反应
- 万用表测不到电压

**排查步骤：**

```
步骤 1：检查 USB 线
├─ 更换 USB 线测试
├─ 检查 USB 线是否支持数据传输
└─ 尝试不同 USB 接口

步骤 2：检查 USB 接口
├─ 目视检查 USB-C 母座焊接
├─ 检查是否有虚焊
└─ 测 USB 母座引脚通断

步骤 3：检查电源路径
├─ 测 USB 5V 输入（C1 两端）
├─ 测 AMS1117 输入（Pin 3）
├─ 测 AMS1117 输出（Pin 2）
└─ 测 3.3V 电源节点

步骤 4：检查短路
├─ 断电测 VCC 对地电阻
├─ 正常应 >1kΩ
└─ 如 <100Ω，存在短路
```

**常见原因：**

| 原因 | 检查方法 | 解决方法 |
|------|---------|---------|
| USB 线损坏 | 更换线缆 | 更换优质 USB 线 |
| USB 接口虚焊 | 目视+万用表 | 补焊 |
| 稳压芯片损坏 | 测输入/输出电压 | 更换芯片 |
| 电容短路 | 测电容两端电阻 | 更换电容 |
| 电源 LED 极性错误 | 观察 LED 方向 | 重新焊接 |

---

### 1.2 电流过大

**症状：**
- 上电后电流 >500mA
- USB 接口发热
- 电源芯片发热严重
- 电脑提示 USB 过流

**排查步骤：**

```
步骤 1：立即断电
├─ 拔掉 USB 线
├─ 避免损坏元件
└─ 准备排查工具

步骤 2：目视检查
├─ 检查焊锡连焊
├─ 检查异物短路
├─ 检查元件方向
└─ 使用放大镜辅助

步骤 3：分区域排查
├─ 断开电源部分，测电流
├─ 断开主控部分，测电流
├─ 断开 USB 部分，测电流
└─ 逐步缩小范围

步骤 4：万用表排查
├─ 测各电源节点对地电阻
├─ 找出阻值异常区域
└─ 重点检查该区域
```

**常见原因：**

| 原因 | 检查方法 | 解决方法 |
|------|---------|---------|
| 电源短路 | 测 VCC 对地电阻 | 清除短路点 |
| 芯片焊接连焊 | 目视检查 | 清除连焊 |
| 电容短路 | 测电容电阻 | 更换电容 |
| 芯片损坏 | 芯片发热严重 | 更换芯片 |

## 二、通信问题

### 2.1 无法识别串口

**症状：**
- 设备管理器中无串口设备
- 或显示"未知设备"
- 或显示黄色感叹号

**排查步骤：**

```
步骤 1：检查驱动
├─ 打开设备管理器
├─ 查看"端口(COM 和 LPT)"
├─ 如无设备，安装驱动
└─ 下载 CH340 驱动并安装

步骤 2：检查 USB 线
├─ 确认线缆支持数据传输
├─ 某些线仅支持充电
└─ 更换优质 USB 线

步骤 3：检查 CH340 焊接
├─ 目视检查芯片焊接
├─ 测 CH340 电源（Pin 8）
├─ 测 USB 信号线（D+/D-）
└─ 检查外围电路

步骤 4：检查 USB 接口
├─ 检查 USB-C 焊接
├─ 测 USB D+/D- 连通性
└─ 检查 ESD 保护芯片
```

**常见原因：**

| 原因 | 检查方法 | 解决方法 |
|------|---------|---------|
| 驱动未安装 | 设备管理器检查 | 安装 CH340 驱动 |
| USB 线仅充电 | 更换线缆测试 | 使用数据线 |
| CH340 虚焊 | 目视+万用表 | 补焊 |
| USB D+/D- 断路 | 测连通性 | 修复断路 |

---

### 2.2 无法进入下载模式

**症状：**
- 烧录时提示"连接失败"
- 串口输出乱码
- 无法进入 Bootloader

**排查步骤：**

```
步骤 1：检查按键操作
├─ 按住 BOOT 键（不要松开）
├─ 短按 RST 键（1秒后松开）
├─ 松开 BOOT 键
└─ 查看串口输出

步骤 2：检查按键焊接
├─ 测 BOOT 键通断
├─ 测 RST 键通断
├─ 按下时应有通断变化
└─ 检查上拉电阻

步骤 3：检查串口连接
├─ 测 TX/RX 连通性
├─ TX 应连接到 CH340 RX
├─ RX 应连接到 CH340 TX
└─ 检查是否交叉连接

步骤 4：检查芯片状态
├─ 测 ESP32 电源
├─ 测 EN 引脚电平（应高）
├─ 测 IO0 引脚电平
└─ 按下 BOOT 时 IO0 应低
```

**常见原因：**

| 原因 | 检查方法 | 解决方法 |
|------|---------|---------|
| 按键操作错误 | 按正确顺序操作 | 按住 BOOT → 按 RST → 松开 BOOT |
| 按键虚焊 | 测按键通断 | 补焊 |
| TX/RX 接反 | 查看原理图 | 交叉连接 |
| 上拉电阻缺失 | 测电阻值 | 补焊电阻 |

## 三、显示问题

### 3.1 墨水屏不显示

**症状：**
- 屏幕无任何显示
- 或显示异常图案
- 或显示后消失

**排查步骤：**

```
步骤 1：检查排线连接
├─ 确认排线方向正确
├─ 检查排线是否插到底
├─ 检查 FPC 连接器锁扣
└─ 尝试重新插拔

步骤 2：检查 FPC 焊接
├─ 目视检查焊接质量
├─ 测连接器引脚通断
├─ 检查是否有焊锡进入
└─ 必要时补焊

步骤 3：检查电源
├─ 测墨水屏 VCC
├─ 应为 3.3V
└─ 检查接地

步骤 4：检查信号线
├─ 测 SPI 信号线（SCK/MOSI/CS/DC/RST/BUSY）
├─ 检查是否连通
└─ 检查是否短路

步骤 5：检查固件
├─ 重新烧录固件
├─ 确认屏幕型号配置正确
└─ 查看串口日志
```

**常见原因：**

| 原因 | 检查方法 | 解决方法 |
|------|---------|---------|
| 排线方向错误 | 查看排线标记 | 正确插入 |
| FPC 连接器虚焊 | 目视+万用表 | 补焊 |
| 排线损坏 | 目视检查 | 更换排线 |
| 固件配置错误 | 查看配置 | 重新编译烧录 |

---

### 3.2 显示异常

**症状：**
- 显示条纹
- 颜色异常
- 部分区域不显示
- 显示模糊

**排查步骤：**

```
步骤 1：检查刷新模式
├─ 确认固件支持三色屏
├─ 检查刷新序列
└─ 查看串口日志

步骤 2：检查信号质量
├─ 测 SPI 时钟信号
├─ 检查信号完整性
└─ 必要时降低 SPI 速度

步骤 3：检查电源稳定性
├─ 测刷新时电压波动
├─ 检查电容容量
└─ 增加滤波电容

步骤 4：检查屏幕本身
├─ 更换屏幕测试
├─ 排除屏幕损坏
└─ 检查 FPC 排线
```

**常见原因：**

| 原因 | 检查方法 | 解决方法 |
|------|---------|---------|
| SPI 速度过快 | 查看配置 | 降低 SPI 时钟 |
| 电源不稳定 | 示波器测电压 | 增加滤波电容 |
| 屏幕损坏 | 更换测试 | 更换屏幕 |
| 固件问题 | 查看日志 | 更新固件 |

## 四、功能问题

### 4.1 WiFi 连接失败

**症状：**
- 无法创建热点
- 无法连接路由器
- 连接后频繁断线

**排查步骤：**

```

├─ ESP32-S3 模组内置天线
├─ 确认模组焊接良好
└─ 避免金属遮挡

步骤 2：检查电源
├─ WiFi 发射时电流较大
├─ 测 3.3V 是否稳定
└─ 检查电源供电能力

步骤 3：检查配置
├─ 查看 WiFi 配置
├─ 确认 SSID/密码正确
└─ 检查信道设置

步骤 4：查看日志
├─ 连接串口查看日志
├─ 查找错误信息
└─ 根据错误排查
```


## 五、焊接问题

### 5.1 虚焊

**识别方法：**
- 焊点灰暗无光泽
- 引脚可晃动
- 万用表测不通

**解决方法：**
1. 清洁焊盘和引脚
2. 重新加热焊点
3. 添加适量焊锡
4. 确认焊锡流动

---

### 5.2 连焊

**识别方法：**
- 相邻焊点连在一起
- 万用表测短路

**解决方法：**
1. 使用吸锡器吸除多余焊锡
2. 清洁烙铁头
3. 重新逐点焊接
4. 使用助焊剂

---

### 5.3 焊盘脱落

**识别方法：**
- 焊盘从 PCB 板脱落
- 铜箔断裂

**解决方法：**
1. 刮开阻焊层露出铜箔
2. 使用跳线连接
3. 固定跳线
4. 测试连通性

## 六、测试工具使用

### 6.1 万用表使用

**测电压：**
```
1. 选择直流电压档（20V）
2. 黑表笔接地（GND）
3. 红表笔接触测试点
4. 读取电压值
```

**测电阻：**
```
1. 断电状态
2. 选择电阻档（20kΩ）
3. 两表笔接触测试点
4. 读取电阻值
```

**测通断：**
```
1. 选择蜂鸣档
2. 两表笔接触测试点
3. 蜂鸣器响表示导通
```

---

### 6.2 串口调试

**连接方法：**
```
USB 线 → 设备 USB-C 接口
↓
电脑识别串口（COM 口）
↓
打开串口调试助手
↓
设置波特率：115200
↓
查看日志输出
```

**常用命令：**
```powershell
# 查看可用串口
mode

# 烧录固件
idf.py -p COM3 flash

# 查看日志
idf.py -p COM3 monitor

# 烧录并查看日志
idf.py -p COM3 flash monitor
```

## 七、预防措施

### 7.1 焊接前

- [ ] 检查 PCB 板质量
- [ ] 清洁焊盘
- [ ] 检查元器件
- [ ] 准备好工具

### 7.2 焊接中

- [ ] 控制烙铁温度（350-380°C）
- [ ] 控制焊接时间（2-3秒/点）
- [ ] 使用助焊剂
- [ ] 及时清洁烙铁头

### 7.3 焊接后

- [ ] 目视检查所有焊点
- [ ] 万用表测关键节点
- [ ] 清洁焊锡渣
- [ ] 检查元器件方向
