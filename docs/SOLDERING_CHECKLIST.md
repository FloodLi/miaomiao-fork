## 三、焊接质量标准

### 优良焊点特征
- ✅ 焊点呈圆锥形
- ✅ 表面光亮平滑
- ✅ 润湿角 <90°
- ✅ 无拉尖、毛刺
- ✅ 焊锡量适中（覆盖焊盘和引脚）

### 不良焊点类型

**虚焊**
- 现象：焊点灰暗、无光泽
- 原因：焊接温度不够或时间太短
- 处理：重新加热补焊

**连焊**
- 现象：相邻焊点连在一起
- 原因：焊锡过多或烙铁停留时间过长
- 处理：使用吸锡器清理

**冷焊**
- 现象：焊点粗糙、颗粒状
- 原因：焊锡未完全熔化
- 处理：重新加热

**焊锡过多**
- 现象：焊点过大、球形
- 原因：焊锡丝供给过多
- 处理：吸除多余焊锡

**焊锡过少**
- 现象：焊点过小、引脚外露
- 原因：焊锡丝供给不足
- 处理：补焊

## 五、常见问题排查

### 问题 1：上电无反应

**可能原因**
1. 电源短路
2. 稳压芯片损坏
3. USB 接口虚焊
4. 电源 LED 极性错误

**排查步骤**
1. 测 USB 5V 输入
2. 测 3.3V 输出
3. 检查电流消耗
4. 检查电源 LED

---

### 问题 2：电流过大

**可能原因**
1. 电源短路
2. 芯片损坏
3. 电容短路
4. 焊锡连焊

**排查步骤**
1. 断电测对地电阻
2. 分区域排查
3. 目视检查连焊
4. 逐一排除

---

### 问题 3：无法识别串口

**可能原因**
1. CH340 虚焊
2. USB 线问题
3. 驱动未安装
4. USB 接口虚焊

**排查步骤**
1. 更换 USB 线
2. 安装驱动
3. 检查 CH340 焊接
4. 测 USB 信号线

---

### 问题 4：墨水屏不显示

**可能原因**
1. 排线连接错误
2. FPC 连接器虚焊
3. 排线损坏
4. 固件问题

**排查步骤**
1. 检查排线方向
2. 重新插拔排线
3. 检查 FPC 焊接
4. 重新烧录固件

---
