# 双屏支持说明

## 支持的屏幕型号

本项目支持两种尺寸的三色墨水屏，可通过 Web 界面或 NVS 配置切换：

### 1. 4.2" 三色墨水屏（默认）

**型号：** GDEH042Z96 / Waveshare 4.2" BWR

**规格：**
- 分辨率：400 × 300 像素
- 驱动芯片：SSD1619
- 颜色：黑白红三色（BWR）
- 刷新时间：约 15 秒
- 视角：近 180°

**特点：**
- ✅ 成本较低（约 ¥120）
- ✅ 尺寸适中，适合桌面摆放
- ✅ 功耗较低
- ⚠️ 分辨率相对较低

**适用场景：**
- 电子相册
- 天气显示
- 课程表
- 待办事项

---

### 2. 5.83" 三色墨水屏

**型号：** GDEW0583Z21 / Waveshare 5.83" BWR

**规格：**
- 分辨率：648 × 480 像素
- 驱动芯片：UC8179
- 颜色：黑白红三色（BWR）
- 刷新时间：约 20 秒
- 视角：近 180°

**特点：**
- ✅ 分辨率高，显示更清晰
- ✅ 屏幕更大，信息量更多
- ✅ 适合显示复杂内容
- ⚠️ 成本较高（约 ¥200）
- ⚠️ 功耗略高

**适用场景：**
- 电子书阅读
- 复杂图表显示
- 会议门牌
- 公告板

## 切换方法

### 方法 1：Web 界面切换（推荐）

1. 打开 Web 配置页面：`http://epd.local/config`
2. 找到"屏幕配置"卡片
3. 选择屏幕型号：
   - 4.2" SSD1619
   - 5.83" UC8179
4. 点击"保存"
5. 设备自动重启

### 方法 2：HTTP API 切换

```bash
# 切换到 4.2" 屏幕
curl -X POST http://epd.local/panel_config \
  -H "Content-Type: application/json" \
  -d '{"panel":0}'

# 切换到 5.83" 屏幕
curl -X POST http://epd.local/panel_config \
  -H "Content-Type: application/json" \
  -d '{"panel":1}'
```

### 方法 3：NVS 配置

```c
// 在代码中设置
#include "nvs_flash.h"
#include "nvs.h"

nvs_handle_t h;
nvs_open("epd", NVS_READWRITE, &h);
nvs_set_u8(h, "panel", 1);  // 0=4.2", 1=5.83"
nvs_commit(h);
nvs_close(h);
```

## 功能适配

### 自动适配功能

项目代码会根据屏幕尺寸自动调整：

1. **字体大小**
   - 4.2"：使用 1x 缩放
   - 5.83"：使用 2x 缩放

2. **布局调整**
   - 自动计算行列数
   - 优化显示密度
   - 适配不同分辨率

3. **图片缩放**
   - 自动缩放到屏幕尺寸
   - 保持宽高比
   - 居中显示

### 需要手动调整的功能

某些功能可能需要根据屏幕调整：

1. **课程表**
   - 4.2"：紧凑模式
   - 5.83"：标准模式

2. **天气显示**
   - 图标大小
   - 字体大小
   - 布局间距

3. **日历显示**
   - 日期格子大小
   - 农历字体
   - 节日标注

## 常见问题

### Q1: 如何判断当前使用的是哪种屏幕？

**A:** 
- 查看 Web 配置页面
- 查看串口日志：`ESP_LOGI(TAG, "EPD start: %s %dx%d"...);`
- 测量屏幕尺寸

### Q2: 可以在运行时切换屏幕吗？

**A:** 
- 可以通过 Web 界面切换
- 需要重启设备生效
- NVS 配置会保存

### Q3: 两种屏幕的接口一样吗？

**A:** 
- SPI 接口相同
- FPC 排线可能不同
- 需要确认连接器规格

### Q4: 刷新时间为什么不同？

**A:** 
- 屏幕尺寸不同
- 像素数量不同
- 驱动芯片不同
- 物理特性决定

### Q5: 功耗差异大吗？

**A:** 
- 刷新时功耗相近
- 待机功耗都很低
- 5.83" 略高 10-20%
